# Data access and redistribution

No EEG recordings or participant-level derived data are distributed in this
repository. The manuscript uses the following public datasets:

| Dataset | Role in the study |
| --- | --- |
| Sleep-EDF Expanded | Sleep-domain representation learning and sleep-side analyses |
| CAP Sleep Database (CAPSleep) | External sleep-stage transfer and sleep-physiology analyses |
| EEG Motor Movement/Imagery Dataset (EEGMMIDB) | Cross-sectional MI-BCI aptitude and awake-physiology analyses |
| Cho2017 | Independent cross-sectional MI-BCI aptitude cohort and awake-domain control source |
| Stieger2021 | Longitudinal Session 1 to Session 2 BCI-performance analysis |
| WBCIC-SHU | Independent awake-rest source for the matched-source and continuation analyses |
| OpenBMI (Lee2019) | External motor-imagery donor cohort for MI-specialized comparison encoders |
| Simultaneous EEG and fMRI Signals During Sleep from Humans | Same-subject wake-to-sleep identity analysis |

Obtain each dataset from the original provider using the dataset record cited in
the manuscript. Access, use, and redistribution remain governed by the original
provider's terms. Local data paths should be supplied at runtime and must not be
committed to this repository.
